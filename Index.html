В современных браузерах (Chrome, Safari) доступ к камере и гироскопу жестко заблокирован на обычных http:// сайтах на уровне самого браузера (это защита от слежки). Обойти это просто строчкой в коде нельзя — браузер выдаст ошибку navigator.mediaDevices is undefined. Но есть 3 простых способа запустить эту программу вообще без настройки HTTPS, сертификатов и хостингов. Кроме того, ниже я добавил в код режим работы без камеры (рисование взглядом + тапом), который запустится даже просто при открытии файла index.html из папки телефона! Способ 1. Скрытая настройка в Chrome на телефоне (Самый быстрый) Если вы запускаете сайт с компьютера по Wi-Fi (например, по адресу [http://192.168.1.5:8080](http://192.168.1.5:8080)), можно за 10 секунд разрешить браузеру на телефоне включать камеру и VR без HTTPS: * Откройте браузер Chrome на телефоне. * Введите в адресную строку: chrome://flags/#unsafely-treat-insecure-origin-as-secure * В текстовое поле впишите адрес вашего сервера (например, [http://192.168.1.5:8080](http://192.168.1.5:8080)). * Переключите статус с Disabled на Enabled и нажмите кнопку Relaunch (Перезапустить) внизу. * Всё! Теперь для этого адреса камера, трекинг рук и VR работают по обычному http://. Способ 2. Запуск через адрес localhost По стандарту безопасности адрес http://localhost (или [http://127.0.0.1](http://127.0.0.1)) считается браузером полностью безопасным — на нем HTTPS не требуется вообще: * Прямо на телефоне: Скачайте на Android бесплатное приложение Simple HTTP Server или KSWeb, выберите папку с вашим файлом index.html и откройте в браузере телефона http://localhost:8080. Камера заработает сразу! * Через USB-кабель от ПК: Подключите телефон к ПК, откройте в Chrome на компьютере chrome://inspect/#devices, включите Port forwarding (например, порт 8080 на localhost:8080) и откройте http://localhost:8080 на телефоне. Способ 3. Обновленный код (Работает даже без сервера и без камеры!) Я переписал код так, чтобы он не ломался без HTTPS. Теперь в нем есть два режима: * С трекингом рук (если есть камера): работает через localhost или флаг из Способа 1. * Автономный режим (если открыли просто как файл file:// или по http://): если браузер заблокировал камеру, автоматически включается 3D-лазерная кисть по центру взгляда. Вы крутите головой или водите пальцем по экрану, а при зажатии экрана (или кнопки на VR-очках) в воздухе рисуется объемная 3D-модель! Сохраните этот код как index.html и просто откройте на телефоне: AirSketch VR — Работает без HTTPS
